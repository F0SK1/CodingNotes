05 / INTERACCIÓN

Formularios que se entienden y se pueden usar

Un formulario recoge datos mediante controles claros. Cada campo necesita una etiqueta asociada y un tipo de entrada adecuado.

Formularios: recoge información

Agrupa los controles relacionados con <form>. Vincula cada <label> con el id del campo usando for; así, al pulsar la etiqueta también se activa el control. Elige el tipo de entrada que corresponda, marca los campos obligatorios con required y usa <textarea> para texto largo.

  • text, email y password recogen tipos distintos de texto.
  • checkbox permite elegir varias opciones; radio permite elegir una dentro de un grupo con el mismo name.
  • name identifica el dato enviado; required activa una validación básica del navegador.

Un formulario de registro

<form action="../html.html" method="get">
  <label for="name">Name</label>
  <input id="name" name="name"
    type="text" required>

  <label for="email">Email</label>
  <input id="email" name="email"
    type="email" required>

  <label for="message">Message</label>
  <textarea id="message" name="message"></textarea>

  <button type="submit">Send</button>
</form>

Prueba los campos

Este ejemplo solo comprueba los campos en tu navegador; no envía ni guarda tus datos.

Accesibilidad y buenas prácticas

No uses el placeholder como sustituto de una etiqueta. Los campos deben tener un nombre (atributo name) para que sus datos se incluyan al enviar el formulario.
