01 · FUNDAMENTOS DE HTML

HTML: estructura con significado

Antes de pensar en colores o animaciones, una página necesita una estructura clara. HTML organiza el contenido y explica qué papel cumple cada parte.

Documento básico HTML semántico Textos y jerarquía Enlaces y rutas Listas Ponlo en práctica

01 / EL PUNTO DE PARTIDA

La anatomía de un documento HTML

Un documento HTML empieza declarando que usa HTML5. Después, el elemento <html> contiene toda la página; <head> guarda información para el navegador y <body> contiene lo que verá la persona.

Código

<!doctype html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi primera página</title>
</head>
<body>
  <h1>Hola, web</h1>
  <p>Esta es mi primera página.</p>
</body>
</html>

Resultado en la página

Hola, web

Esta es mi primera página.

  • <!doctype html> indica al navegador que interprete el documento con los estándares actuales.
  • lang="es" identifica el idioma principal, lo que ayuda a lectores de pantalla y otras herramientas.
  • meta charset="utf-8" permite mostrar correctamente caracteres como ñ y tildes.
  • meta name="viewport" ayuda a que la página se adapte a pantallas pequeñas.

02 / DARLE SENTIDO

Elige etiquetas por lo que significan

Las etiquetas semánticas describen el propósito de su contenido. Así, el documento resulta más fácil de entender para otras personas, navegadores y tecnologías de asistencia.

  • <header> presenta una página o una sección.
  • <nav> agrupa los enlaces de navegación principales.
  • <main> contiene el contenido principal y único de la página.
  • <article> representa contenido independiente, como una publicación o tarjeta.
  • <section> agrupa contenido relacionado bajo un encabezado.
  • <aside> contiene información complementaria.
  • <footer> presenta información final de la página o sección.

<section> o <div>?

Usa <section> para un tema con sentido propio y su encabezado. Usa <div> cuando solo necesitas agrupar elementos para aplicar estilos o maquetar.

No añadas clases por costumbre

Empieza con elementos semánticos. Añade una clase o un id solo cuando necesites identificar ese elemento para estilos, enlaces internos o comportamiento.

Una tarjeta semántica

<article>
  <header>
    <h3>Una idea, bien estructurada</h3>
  </header>
  <p>Cada etiqueta aporta significado.</p>
  <footer>Tema: HTML semántico</footer>
</article>

03 / JERARQUÍA Y ÉNFASIS

Organiza el contenido para que se lea mejor

Los encabezados crean una jerarquía, los párrafos agrupan ideas y las etiquetas de énfasis resaltan lo importante. Elige cada elemento por su significado, no solo por su apariencia.

  • <h1> a <h6> organizan los títulos desde el tema principal hasta los subtemas. Mantén el orden lógico y no saltes niveles solo para cambiar el tamaño.
  • <p> agrupa una idea o párrafo de texto.
  • <strong> marca importancia; <em> añade énfasis.
  • <hr> indica un cambio temático entre partes del contenido.

La jerarquía en código

<h2>Aprender HTML</h2>
<p>Una página se construye paso a paso.</p>
<h3>Empieza por la estructura</h3>
<p>Usa <strong>etiquetas con significado</strong>
  y añade <em>énfasis cuando haga falta</em>.</p>
<hr>
<p>Después, sigue con el siguiente tema.</p>

04 / CONECTAR PÁGINAS

Enlaces y rutas relativas

Un enlace usa <a> y el atributo href para indicar su destino. Las rutas relativas se calculan desde la carpeta del archivo actual: ../index.html sube un nivel; desde la raíz, pages/html.html entra en la carpeta pages.

  • Para abrir un sitio externo en otra pestaña, usa target="_blank" junto con rel="noopener noreferrer".
  • Usa rutas relativas para que los enlaces sigan funcionando al mover el sitio entre equipos o servidores.

Enlaces en HTML

<a href="../index.html">Volver al inicio</a>
<a href="https://developer.mozilla.org/"
  target="_blank" rel="noopener noreferrer">
  Consultar MDN
</a>
